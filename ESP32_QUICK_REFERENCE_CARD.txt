═══════════════════════════════════════════════════════════════════
MULTIPLE CAMERA SETUP
═══════════════════════════════════════════════════════════════════

If using multiple ESP32-CAM devices, assign different IPs:

┌────────────────────────────────────────────────────────────────┐
│ Camera 1:  192.168.1.100   →   Stream 1 in dashboard          │
│ Camera 2:  192.168.1.101   →   Stream 2 in dashboard          │
│ Camera 3:  192.168.1.102   →   Stream 3 in dashboard          │
└────────────────────────────────────────────────────────────────┘

Configuration in Arduino code (Project_Capstone.ino):

Camera 1: #define STATIC_IP 192,168,1,100
Camera 2: #define STATIC_IP 192,168,1,101
Camera 3: #define STATIC_IP 192,168,1,102


═══════════════════════════════════════════════════════════════════
NETWORK COMPATIBILITY
═══════════════════════════════════════════════════════════════════

✅ Works with:
   • Home routers (TP-Link, Netgear, Asus, etc.)
   • Office networks (with proper VLAN access)
   • Mobile hotspots (if static IP configured)
   • Mesh networks (Google WiFi, Eero, etc.)

⚠️ May need adjustment for:
   • Corporate firewalls (ports 80, 81)
   • VPN networks
   • Public Wi-Fi (usually blocked)


═══════════════════════════════════════════════════════════════════
POWER REQUIREMENTS
═══════════════════════════════════════════════════════════════════

Voltage:    5V DC
Current:    500mA minimum, 1A recommended
Connector:  Micro USB or USB-C (depending on board)

⚠️ Do NOT power from laptop USB during operation - use wall adapter!
