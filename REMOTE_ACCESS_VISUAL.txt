              SOLUTION 1B: PORT FORWARDING + DDNS
═══════════════════════════════════════════════════════════════════════════

Problem: Public IPs can change (Dynamic IP from ISP)
Solution: Use DDNS (Dynamic Domain Name Service)

SETUP:
1. Register free domain names:
   - site-a.duckdns.org → Always points to Site A's current IP
   - site-b.duckdns.org → Always points to Site B's current IP
   - site-c.duckdns.org → Always points to Site C's current IP

2. Configure DDNS in each site's router
   - Router automatically updates IP every 5 minutes

3. Use in website:
   ┌─────────────────────────────────────────┐
   │ Stream 1: site-a.duckdns.org:8081       │
   │ Stream 2: site-b.duckdns.org:8082       │
   │ Stream 3: site-c.duckdns.org:8083       │
   └─────────────────────────────────────────┘

✅ Now it works even if site IPs change!
